## Runnable app + tests

```bash
npm install
npm start          # http://localhost:3847 — alice/alice123 or bob/bob123
npm test           # Playwright API + E2E (8 tests)
npm run test:report
```

Study materials work offline in the browser — no install required for the HTML/MD editions alone.
